# 分层网格动作 V3（2026-10-20，北京时间）

用户已确认：在现有角色上制作胸部衣料、躯干、前后头发和配饰的可变形网格，并补画运动露出的遮挡区域。保持透明底、原位置、眨眼和音频口型；不要自动点头、摇头。

## 设计

使用现有 102 层原位素材，按连续绘制顺序合并固定在一起的部件，保留独立的衣料、发束、领带和饰物网格。坐标仍为 1086×1448，导出纹理最高为原图的两倍采样；不声称增加了原生细节。原始两张图片保持不变，朋友的降噪工作可以继续。

WebGL 绘制每个部件的三角网格，顶点由固定锚点、呼吸和弹簧跟随控制。头部默认固定；胸部衣料适量起伏，领带和发梢延迟跟随。脸部继续使用已经做好的表情补画。运动幅度限定在小范围，不做大角度转身。

补画优先覆盖领带和胸前发束下面的衣料、皮肤与腰封。生成结果只取遮挡内的像素，避免改动原图可见区域。保留透明背景，运动检查中发现裂缝时修正遮挡层或缩小该部件的相对位移。

## 实现与验收

1. 素材构建：生成独立透明纹理、原位置清单、补画来源和合成预览。验证所有原 PSD 图层恰好归属一个绘制组，静止合成与原图对比。
2. 网格与跟随：测试零参数复原、头部稳定、锚点固定、胸部/头发/配饰不同位移、弹簧稳定、最大幅度下三角形不翻转。
3. 网页接入：保留播放、暂停、音频、减少动态设置；增加部位开关与网格查看，导出离线版。
4. 视觉验收：检查明暗/透明网格背景、呼吸两端、长发摆动、领带根部和胸前遮挡，检查移动端布局与控制台。
5. 代码审查，通过后推送原仓库并验证 Pages 版本。

## 边界

交付为自定义网页分层网格模型，不包含 Cubism 编辑器绑定或 `.moc3`。现有拆图仍有原始边缘噪点；大幅运动和精细逐根头发补画不在本轮验收范围。
